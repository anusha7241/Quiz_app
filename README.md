# Quiz Application 
A simple Python-based Quiz Application that allows users to answer multiple-choice questions and get their final score.

# Description
This project is a beginner-friendly quiz application built using Python.
It presents a set of multiple-choice questions to the user, evaluates their answers, and displays the final score at the end.

# Features

* Multiple-choice questions (MCQs)
* User input handling
* Instant feedback (Correct ❌ / Wrong ✅)
* Final score calculation
* Simple and interactive interface
*

* Basic concepts (lists, dictionaries, loops, conditions)
